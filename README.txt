INZIMAM ALI — PORTFOLIO CONCEPT

OPEN: index.html in any modern desktop or mobile browser.

WHAT IS INCLUDED
- Desktop hero background (wide cinematic image)
- Mobile hero background (portrait cinematic image)
- Responsive premium UI with subtle 3D glass cards
- Navigation, service details, résumé panel, and contact demo
- Reduced-motion accessibility support

CUSTOMIZE BEFORE PUBLISHING
1) Verify résumé timeline and factual details.
2) Replace the portfolio profile with your finalized professional experience.
3) Connect the contact form to a real email/form provider; the demo currently copies an inquiry and never sends it.
4) If desired, add LinkedIn and a verified PDF résumé to the profile panel.
5) Web fonts are requested from Google Fonts; the page includes system fallbacks.

Suggested deploy options: Netlify, Vercel, GitHub Pages or your current hosting.
All photo assets are in the assets/ directory.
